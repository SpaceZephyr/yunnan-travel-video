| 1 | 去大理，别一落地就急着环洱海。先看懂这张图：苍山在西边，洱海在东边，古城夹在中间。 |
| 2 | 把大理分成三块：古城和苍山、洱海西岸、洱海东岸。照着这三块玩，基本不走回头路。 |
| 3 | 出发前准备几样大理特有的：防晒霜、墨镜、一件外套。这里海拔两千米左右，太阳很晒，早晚温差又大。 |
| 4 | 想坐索道上苍山，票提前在网上订好，节假日人多。 |
| 5 | 怎么到？大多数人坐动车到大理站，昆明过来两个小时左右，丽江过来一个半小时起。 |
| 6 | 大理站在下关，离古城还有十几公里，打车四十分钟左右。 |
| 7 | 坐飞机就落凤仪机场，到古城打车差不多一个小时。 |
| 8 | 到了以后怎么动？古城里靠走，西岸的廊道骑车，东岸离得远，直接打车或者包车。 |
| 9 | 第一次来，我更推荐住古城，吃饭打车都方便。想推开窗看洱海日出，就住才村或者龙龛。 |
| 10 | 双廊住一晚体验就够了，它在湖的东北角，去哪都远。 |
| 11 | 第一块，古城和苍山。上午先去感通索道，从古城打车不到二十分钟。下午两点以后就不能上山了，一定早点去。 |
| 12 | 坐到两千五百多米的上站，往清碧溪走一小段，回头看，整片洱海和古城都在脚下。 |
| 13 | 下山回到古城南门，顺着人民路一路逛到北门。古城本身不要门票。 |
| 14 | 出北门再往北两公里，就是崇圣寺三塔，走路半小时，打车几分钟。一千多年的塔背靠苍山，要单独买票。 |
| 15 | 第二块，洱海西岸。从龙龛码头上生态廊道，这条路不让汽车进，全天免费。 |
| 16 | 直接扫廊道里的共享单车，古城租的电动车可能会被拦在外面。 |
| 17 | 往北骑过才村，到磻溪的S湾，苍山和洱海会同时挤进一个弯道里。 |
| 18 | 再往北就是喜洲古镇，白族老院子还住着人，路边买一块刚出炉的喜洲粑粑。从龙龛骑到这里十几公里，慢慢骑要半天。 |
| 19 | 第三块，洱海东岸。从喜洲打车四十多分钟到双廊，在湖边找个位置坐一下午。 |
| 20 | 日落前往南走，到小普陀，湖里一座小岛上建了座小庙。在这儿看太阳落到对岸的苍山后面，再沿东岸回下关。 |
| 21 | 怎么组合？玩两天，第一天古城加苍山；第二天从西岸骑到喜洲，再绕到东岸看日落，正好环湖一圈。 |
| 22 | 只有一天，就上午苍山，下午古城和三塔，傍晚去龙龛的湖边坐一会儿。 |
| 23 | 收藏这条，到了大理照着三块走：先上山，再环湖。 |
